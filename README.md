## FuelDrop

> Find the cheapest petrol near you — on your phone or on your drive.

![iOS 17+](https://img.shields.io/badge/iOS-17%2B-000000?style=flat&logo=apple&logoColor=white)
![CarPlay](https://img.shields.io/badge/CarPlay-supported-1C1C1E?style=flat&logo=apple&logoColor=white)
![Swift](https://img.shields.io/badge/Swift-SwiftUI-F05138?style=flat&logo=swift&logoColor=white)
![Status](https://img.shields.io/badge/status-in%20development-F5A623?style=flat)

FuelDrop helps UK drivers find the cheapest nearby petrol station in seconds — with full CarPlay support so you never have to look down while driving.

### Features

- **Nearby stations** — sorted by price and distance, updated live
- **CarPlay integration** — glanceable prices before you pull in
- **Widgets** — home screen and lock screen support
- **Clean design** — Scandinavian-inspired UI, built in SwiftUI

### Built with

`Swift` `SwiftUI` `CarPlay` `WidgetKit` `MapKit` `Figma`
